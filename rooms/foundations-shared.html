Foundations

A depends-on map you can defend

Learn it in 5 minutes

HTML

About five minutes of reading

Every later track names the foundation it needs. If that foundation is missing, the track's lab will show the same fault.

Telephony depends on the instance and on quotas. Flows depend on telephony only because a number has to enter somewhere. Lambda depends on IAM. The CCP depends on the network lesson. Analytics depends on Kinesis and S3. Global Resiliency depends on identity, numbers, and a supported Region pair.

The Ecosystem track depends on all of those, because WFM, quality, E911, and the CRM are consumers of ContactId, recordings, agent events, and profiles.

  • Read the depends-on line on each track before you skip ahead.
  • A migration bridge without flows and routing is a glossary, not a plan.
  • E911 depends on Profiles, Lambda, and an outbound whisper flow.
  • Price estimates depend on the rate card date, which this campus stamps as 14 October 2026.

Number on this page: Tracks 18. Foundations through Ecosystem

Glossary

  • Contact One interaction: a call, chat, task, or email. A transfer usually creates another contact linked by PreviousContactId and NextContactId.
  • Connect Customer The name used from 28 Apr 2026 for the contact center product previously called Amazon Connect.
  • CloudWatch Metrics and flow logs. Alarm at 80 percent of a quota, which is the operations guidance in the email quota note.
  • Kinesis Data Streams The durable stream for CTRs and agent events when more than one consumer must read them.

Config and troubleshooting

Treating tracks as independent products.

IAM, Lambda, S3, Kinesis, and CloudWatch are not inside the instance. This stack creates the instance and turns on flow logs and Contact Lens.

CfnInstance AWS::Connect::Instance

CloudFormation study snippet
AWSTemplateFormatVersion: "2010-09-09"
Description: Connect instance with flow logs and Contact Lens
Resources:
  CampusInstance:
    Type: AWS::Connect::Instance
    Properties:
      IdentityManagementType: SAML
      InstanceAlias: campus-demo
      Attributes:
        InboundCalls: true
        OutboundCalls: true
        ContactflowLogs: true
        ContactLens: true

Cross-platform bridges

A CUCM calling search space is not a routing profile, but the profile is the closest idea of 'who can receive what'. A partition is not a Connect object. A UCCX CSQ and a UCCE skill group map to a queue. Precision steps map to routing criteria. A script, an Architect flow, and an Avaya vector map to a contact flow.
