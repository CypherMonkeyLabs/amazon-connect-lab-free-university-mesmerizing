CCP and workspace

Streams is the supported way to embed the CCP

Learn it in 5 minutes

HTML

About five minutes of reading

If you must hide the CCP inside another app, use amazon-connect-streams. Do not scrape the page.

The library initializes a CCP iframe, then emits agent and contact events. You can run it media-less, which is useful for a supervisor wall and useless as a phone. Softphone options have to be turned on for audio, and the host page has to be on the approved origin.

The GitHub repository is amazon-connect/amazon-connect-streams. Read its event list. Login, contact incoming, connected, and ended are the ones a screen pop needs.

  • Init once. A second init on navigation is a classic bug.
  • Destroy the session on sign-out.
  • Do not store the agent's password in your app. Use SAML.
  • Media still needs UDP 3478. The library does not tunnel it.

Number on this page: Library streams. amazon-connect-streams

Glossary

  • CCP Contact Control Panel. The browser phone and contact UI the agent uses.
  • Agent workspace The fuller desktop around the CCP: profiles, cases, step-by-step views, and third-party apps.
  • Streams API The amazon-connect-streams library. It embeds or replaces the CCP and listens to agent and contact events.
  • Softphone media The WebRTC audio path. It needs outbound UDP 3478 to the Regional TurnNlb domain.

Config and troubleshooting

An iframe of the admin website as a shortcut.

A custom CCP using amazon-connect-streams has to be served from an origin you approve on the instance. The softphone still needs UDP 3478. Approving the origin does not open that port.
