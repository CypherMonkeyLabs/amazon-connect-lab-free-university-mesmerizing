Porting without losing the rollback

Learn it in 5 minutes

HTML

About five minutes of reading

A port is a date with the losing carrier. It is not a flow change.

You submit the port with the same kind of Support request the quota page describes. You need a letter of authorization and a firm order commit date. Until that date, the old platform still owns the number.

Dual-run means the old platform and Connect are both built, and you can move the number back if the first day fails. Practice the rollback before the port window, not during it.

  • Match the caller ID and any CNAM story you actually have. Do not promise caller-name display the product does not set.
  • Internal extensions can stay on CUCM. Only the public number has to move.
  • Update the CRM screen pop to the new ContactId in the same window.
  • Tell the WFM and recording tools the storage path before the port, or the first day has no recordings in the old tool.

Number on this page: Owners 2. Losing carrier and Connect, until the FOC date

Confirm before relying. Prices, quotas, and exam names change. Use the source linked on this page.

Glossary

  • DID A direct inward dial number. In the US it is carried by one carrier and priced per day plus per minute.
  • Toll-free number A number the caller does not pay long-distance to dial. US toll-free numbers are registered with SOMOS and can use more than one carrier.
  • UIFN Universal International Freephone number. One of the four number types Connect sells, with DID, toll-free, and shared cost.
  • Porting Moving a number from another carrier onto Connect. The quota page points you at the same Support form used for quota increases.

Cross-platform bridges

A CUCM calling search space is not a routing profile, but the profile is the closest idea of 'who can receive what'. A partition is not a Connect object.
