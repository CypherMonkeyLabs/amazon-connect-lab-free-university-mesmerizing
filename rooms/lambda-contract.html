The response contract

Learn it in 5 minutes

HTML

About five minutes of reading

Connect does not debug your function. It branches.

Match the block's response validation. A string map is a flat object of strings. JSON validation allows nested JSON. The re:Post guidance says to keep the payload small, with 32 KB as the figure people hit, and to restrict values to characters Connect accepts when you are on a string map.

Print the ContactId. Correlate by time only if you forgot.

  • Idempotent writes. Retries happen.
  • Timeouts in the Lambda console must be higher than the block timeout or you will add a second failure mode.
  • Cold starts count against the 8 seconds.
  • Secrets stay in the function environment or in Secrets Manager, not in flow attributes.

Number on this page: Retries 3. On throttle or HTTP 500, until the block timeout

Glossary

  • Lambda synchronous timeout At most 8 seconds. The function's own timeout can be longer. The flow still takes the Error or Timeout branch at 8 seconds.
  • Lambda asynchronous mode The flow continues without waiting. You can wait up to 60 seconds with a Wait block. A sequence of Lambda calls must finish within 20 seconds.
  • String map A flat object of string keys and string values. One of the two Lambda response shapes.
  • CloudFormation AWS::Connect::ContactFlow A stack resource whose content is flow-language JSON. Use it to move a flow between instances.

Config and troubleshooting

Returning a Python dict with numbers and lists to a string-map block.

Two pieces: a resource policy that trusts connect.amazonaws.com, and an integration association so the flow can select the function. The block still waits at most 8 seconds when InvocationType is SYNCHRONOUS.

Lambda functions IntegrationAssociation

CloudFormation study snippet
Resources:
  InvokePermission:
    Type: AWS::Lambda::Permission
    Properties:
      FunctionName: !Ref FlowHook
      Action: lambda:InvokeFunction
      Principal: connect.amazonaws.com
      SourceArn: !GetAtt CampusInstance.Arn
  LambdaAssociation:
    Type: AWS::Connect::IntegrationAssociation
    Properties:
      InstanceId: !GetAtt CampusInstance.Id
      IntegrationType: LAMBDA_FUNCTION
      IntegrationArn: !GetAtt FlowHook.Arn
