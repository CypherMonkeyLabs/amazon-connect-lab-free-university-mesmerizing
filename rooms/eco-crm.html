CRM configuration and the faults that look like routing bugs

Learn it in 5 minutes

HTML

About five minutes of reading

A wrong screen pop is often an attribute bug, not a Salesforce bug.

Salesforce: sandbox, package, CCP embed or SCC-AC, one case owner, click-to-dial. ServiceNow: imported flows, queue map, hold file under 5 seconds, one router. Both need the customer id written before the agent is offered the contact.

Faults: pop on the wrong record because ANI matched a household, a blank pop because the attribute name does not match the softphone layout, a double agent because AWA and Connect both routed, and a transfer to CUCM that strands the CRM because the second leg has no ContactId.

  • Log the attribute in the flow and in the CRM activity.
  • Search profiles before creating a lead.
  • Outbound click-to-dial uses the queue caller ID.
  • Retest after every managed-package upgrade in a sandbox.

Number on this page: Write the id Before. Transfer to queue

Glossary

  • Start media streaming Sends live customer audio to Kinesis Video Streams for a third-party recorder or bot.
  • Screen recording Records the agent desktop. On the Basic price list it is 0.006 USD per minute.
  • Forecasting and agent scheduling The 4 Aug 2026 name for native WFM: forecast, capacity, schedules, and adherence.
  • Schedule adherence How closely an agent's actual status matched the published schedule. Native metrics appear after schedules are published. Third-party WFM reads agent events.

Config and troubleshooting

Opening the CRM with a hard-coded account so the demo works.

Adherence needs agent events, not a person refreshing a report. ResourceType AGENT_EVENTS and StorageType KINESIS_STREAM is the hook. A second consumer should read the stream, not a second delivery on the instance.

InstanceStorageConfig

CloudFormation study snippet
Resources:
  AgentEvents:
    Type: AWS::Connect::InstanceStorageConfig
    Properties:
      InstanceArn: !GetAtt CampusInstance.Arn
      ResourceType: AGENT_EVENTS
      StorageType: KINESIS_STREAM
      KinesisStreamConfig:
        StreamArn: !GetAtt AgentStream.Arn

Cross-platform bridges

A CUCM calling search space is not a routing profile, but the profile is the closest idea of 'who can receive what'. A partition is not a Connect object. A UCCX CSQ and a UCCE skill group map to a queue. Precision steps map to routing criteria. A script, an Architect flow, and an Avaya vector map to a contact flow.
