ServiceNow Voice

Learn it in 5 minutes

HTML

About five minutes of reading

ServiceNow can own assignment while Connect owns the conversation, if you map the queues on purpose.

The ServiceNow document describes importing contact flows, optional Advanced Work Assignment routing, hold audio no longer than 5 seconds, and transfer-to-agent and transfer-to-queue flows. Queues in Connect get matching AWA queues. AI voice agents, if you bought them, plug into the inbound flow through a flow module.

Oauth and Lambda setup is part of the guide. That Lambda is subject to the same 8-second contract as any other.

  • A 5-second hold file is a hard constraint in that guide. Do not upload a 30-second loop and wonder.
  • Map queues by name in a table you review.
  • The placeholder phone channel is not a real number.
  • Test transfer flows. They are shared with ITSM in the guide's description.

Number on this page: Hold file 5s. ServiceNow's stated maximum

Glossary

  • Salesforce CTI Adapter A managed package plus a serverless app that embeds the CCP in Salesforce.
  • SCC-AC Salesforce Contact Center with Amazon Connect. Voice stays on Connect. Messaging can be Connect or Salesforce.
  • ServiceNow Voice The ServiceNow integration that imports flows, maps queues to Advanced Work Assignment, and can attach AI voice agents.
  • Teams chat bridge A published pattern: a Teams app, Azure Bot Service, API Gateway, Lambda, and StartChatContact. It is chat, not a phone trunk.

Cross-platform bridges

A CUCM calling search space is not a routing profile, but the profile is the closest idea of 'who can receive what'. A partition is not a Connect object. A UCCX CSQ and a UCCE skill group map to a queue. Precision steps map to routing criteria. A script, an Architect flow, and an Avaya vector map to a contact flow.
