Wisdom, Q, and agent assist are one lineage — Ecosystem

Glossary

  • Agent assist The 4 Aug 2026 name for the feature previously called Amazon Q in Connect, which itself included Wisdom.
  • Amazon Q in Connect The 2023 name for generative assistance. The admin guide renamed it agent assist on 4 Aug 2026. IAM still shows the wisdom prefix.
  • Wisdom The 2020 preview name for agent search and recommendations. Folded into Amazon Q in Connect on 28 Nov 2023.
  • Connect assistant block Associates an AI agents domain with the contact so recommendations can run.
