# Start here

1. Serve the repository root (`node scripts/gzip-static.mjs`) and open `http://127.0.0.1:8742/`. A file URL will not load the guide module. Rebuild with `python3 scripts/build_site.py`.
2. Read Foundations if you are new to the AWS account underneath Connect. Read Bridge if you are coming from CUCM, UCCX, UCCE, Webex Contact Center, Genesys, or Avaya. Read Ecosystem if you own workforce, recording, E911, or the CRM.
3. Use Ctrl+K to search. The streak and the lessons you open stay in this browser.
4. Open the 3D map, the CCP studio, and Contact Lens playback from the track drawer. The flow builder and the Erlang C calculator are in Labs. Tips and traps sit on every track. Settings holds the theme, the voice, and reduced motion.
5. The pricing lab is an estimate. The date on it is 14 October 2026.
