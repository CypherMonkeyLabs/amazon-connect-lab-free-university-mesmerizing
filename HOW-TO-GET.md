# How to get a copy

The campus is a static file.

- Browse `campus/index.html` on GitHub Pages once this folder is published.
- Download `releases/amazon-connect-lab.zip`, unzip it, and open `amazon-connect-lab.html`.
- Clone the repository and run `python3 scripts/build_campus.py` if you change a lesson.

Nothing in the file phones home. Search, labs, quiz progress, and the theme stay in `localStorage`.
