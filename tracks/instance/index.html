Every number, user, and flow lives in one instance in one Region. Get this wrong and the rest of the design has no home.

4 rooms. Open one, then use its quiz.

Create the instance on purpose

The instance is the tenancy boundary for users, flows, and numbers. An accidental second instance splits reports and identity.
