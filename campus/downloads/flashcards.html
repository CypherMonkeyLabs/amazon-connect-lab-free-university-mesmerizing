Contact

One interaction: a call, chat, task, or email. A transfer usually creates another contact linked by PreviousContactId and NextContactId.

Flow language concepts

Instance

The Connect container in one Region. It holds users, flows, queues, and numbers. A new account starts at two instances per Region.

Service quotas

Contact flow

The visual program a contact runs. The JSON form is the flow language.

Flow language

Flow module

A published, reusable piece of a flow. Invoke module runs it. Return ends it. Default quota is 200 modules.

Flow block definitions

Contact attribute

A string key and value stored on the contact. Lambda, Lex, and Set contact attributes write them. Screen pop reads them.

Contact attributes

Customer queue flow

The interruptible flow that runs while the customer waits, before an agent joins.

Flow types

Whisper flow

Audio played to one party immediately before the customer and agent are joined.

Flow types

Working queue

The queue selected by Set working queue. Transfer to queue uses it.

Transfer to queue

Routing profile

The list of queues an agent can receive, with channel concurrency, priority, and delay.

Routing profiles

Priority

A number on a queue inside a routing profile. A lower number is served first.

Routing profiles

Delay

Seconds a contact must wait before an agent with that profile can receive it.

Routing profiles

Routing criteria

Ordered steps that tighten or relax who can take the contact. The successor idea to precision-queue steps.

Set routing criteria

Proficiency

A level on a predefined attribute for an agent. Default quota is 10 proficiencies per agent.

Service quotas

Queue

Where a contact waits. Standard queues hold customers. Agent queues hold transfers to a specific user, 10 contacts each by default.

Queues

Hours of operation

The weekly schedule and time zone attached to a queue. Check hours of operation reads it. Overrides cover holidays.

Hours of operation

Quick connect

A one-click transfer target: a user, a queue, or an external number.

Quick connects

DID

A direct inward dial number. In the US it is carried by one carrier and priced per day plus per minute.

Voice channel

Toll-free number

A number the caller does not pay long-distance to dial. US toll-free numbers are registered with SOMOS and can use more than one carrier.

Voice channel

UIFN

Universal International Freephone number. One of the four number types Connect sells, with DID, toll-free, and shared cost.

Pricing appendix

Porting

Moving a number from another carrier onto Connect. The quota page points you at the same Support form used for quota increases.

Service quotas

CCP

Contact Control Panel. The browser phone and contact UI the agent uses.

Set up your network

Agent workspace

The fuller desktop around the CCP: profiles, cases, step-by-step views, and third-party apps.

Agent workspace

Streams API

The amazon-connect-streams library. It embeds or replaces the CCP and listens to agent and contact events.

amazon-connect-streams

Softphone media

The WebRTC audio path. It needs outbound UDP 3478 to the Regional TurnNlb domain.

How CCP uses WebRTC

TURN

The relay used when the browser cannot send media directly. The error text names turn:TurnNlb-....elb.region.amazonaws.com:3478.

Lex V2

The bot service Get customer input calls. Connect stores intent and slots on the contact.

Amazon Lex

Intent

What Lex thinks the caller wants. The flow branches on it.

Amazon Lex

Slot

A value Lex fills, such as an order id. The flow copies it into an attribute.

Amazon Lex

Flow log

A CloudWatch log of each block. Set logging behavior turns it on. The log group is under the instance.

Lambda synchronous timeout

At most 8 seconds. The function's own timeout can be longer. The flow still takes the Error or Timeout branch at 8 seconds.

Lambda block

Lambda asynchronous mode

The flow continues without waiting. You can wait up to 60 seconds with a Wait block. A sequence of Lambda calls must finish within 20 seconds.

Lambda block

String map

A flat object of string keys and string values. One of the two Lambda response shapes.

Identity resolution

Customer Profiles

Case

A durable issue that can span many contacts. Cases became generally available on 3 Oct 2022.

Connect timeline, 25 Sep 2026

Task

A unit of work with no live media. Default concurrent quota is 2500. Tasks can be scheduled up to 90 days ahead.

Service quotas

Security profile

What a user may do in the admin site and the CCP. Different from an IAM policy.

Security profiles

IAM policy

What an AWS principal may call. Connect, Profiles, Cases, and agent assist use different IAM prefixes.

Service authorization, connect

Service-linked role

The role AWS creates so Connect can write to S3, CloudWatch, and other services you name.

Service-linked role

KMS key policy

The key's own allow list. Recordings stay unreadable if the key does not trust the Connect role.

Encryption at rest

SAML

The federated sign-in option. The assertion must carry the routing profile, security profile, and role.

Configure SAML

IAM Identity Center

A common identity provider in front of Connect. It still speaks SAML to the instance.

Configure SAML

Global Resiliency

Forecasting and agent scheduling

The 4 Aug 2026 name for native WFM: forecast, capacity, schedules, and adherence.

Forecasting and scheduling

Schedule adherence

How closely an agent's actual status matched the published schedule. Native metrics appear after schedules are published. Third-party WFM reads agent events.

Forecasting and scheduling

Shrinkage

The fraction of paid time that is not handling contacts. Erlang staffing divides raw agents by one minus shrinkage.

Forecasting and scheduling

Service level

The share of contacts answered inside a target wait. Queue.Duration on the CTR is the usual clock.

Metrics

Occupancy

Handle time plus ACW, divided by signed-in time that was available for work. Agent events supply the clocks.

Agent event streams

ACW

After contact work. The agent is still busy after the customer leaves. It counts in occupancy and in the concurrent task and email quotas.

Agent event streams
