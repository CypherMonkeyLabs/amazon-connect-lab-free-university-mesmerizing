Configuration checklist

Twelve checks before a pilot number takes real traffic.

  1. Instance Region chosen on purpose. Logging on. Storage bucket and key named.
  2. Identity SAML assertion carries routing profile, security profile, and role. Test one user.
  3. Numbers One pilot DID before a port. Caller ID on the queue is a number you may present.
  4. Hours Queue time zone, not the tester's laptop. Holiday override for the next closure.
  5. Flows Error, timeout, and default branches connected. Invoke module for the checks you repeat.
  6. Lambda Associated with the instance. Resource policy allows connect.amazonaws.com. Returns inside 8 seconds.
  7. Lex Alias associated. Speech and DTMF both tested. Fallback reaches a person.
  8. Routing Primary profile priority 1 and delay 0. Overflow has a higher number and a delay.
  9. Recording Set recording behavior, then confirm one object landed. KMS key policy trusts the service role.
  10. Streams Agent events and CTRs have a consumer that tolerates duplicates and joins on ContactId.
  11. Network Endpoint Connectivity tool from an agent PC. Error rate under 2 percent.
  12. E911 Validated address on the agent profile. 933 readback. Security task on a real 911.
