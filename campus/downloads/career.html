Career paths and interview prompts

Badges are not certifications. Say the exam name or the badge name, not both for one credential.

Connect administrator

Instance, hours, queues, routing profiles, security profiles, quotas.

Skill Builder badges (Communications Specialist, Fundamentals, administrator track), passed at 80 percent. Not a proctored Connect specialty exam.

Source: AWS Certification catalog

Flow developer

Flow types, modules, the flow language JSON, Lex slots, and the 8-second Lambda contract.

Connect Developer badge, plus AWS Certified Developer - Associate if the work is Lambda and Streams.

Source: Skill Builder badge blog

Solutions architect

Region pairs, Global Resiliency, IAM prefixes, KMS, S3, Kinesis fan-out.

AWS Certified Solutions Architect - Associate is the closest catalog exam. There is still no Connect specialty.

Source: AWS Certification catalog

Network engineer for the CCP

Domain allow list, UDP 3478, stateless return traffic, VPN kept off the media path, VDI limits.

AWS Certified Advanced Networking - Specialty covers complex networks. Its last day to test is 31 December 2026.

Source: AWS Certification catalog

WFM and quality analyst

Forecasting and agent scheduling, agent events, shrinkage, conversational analytics, evaluation forms.

The AI Fundamentals badge is context. It does not configure a flow. Pair it with the analytics and ecosystem tracks.

Source: Forecasting and scheduling

Interview prompts

Is there an Amazon Connect certification?

Not a specialty exam on the AWS Certification catalog. Connect recognition is a Skill Builder badge at 80 percent. Say which badge, and do not call it certified.

Why did the softphone fail when the agent was signed in?

Signaling can succeed on TCP 443 while media fails on UDP 3478 to TurnNlb.

What replaced Contact Lens and Amazon Q in Connect in 2026?

On 4 August 2026 the admin guide renamed them conversational analytics and agent assist. IAM for assist still shows the wisdom prefix.

How do you migrate a CUCM SIP trunk?

You do not register Connect as a phone. The public number hits a flow. A transfer back to CUCM is Transfer to phone number, and attributes do not ride the PSTN.

What is the honest multi-Region design?

Global Resiliency in a published pair, shifted 10 percent at a time. A second instance you built by hand is not that pattern.

Voice ID in a design written this year?

Support ended 20 May 2026. Remove the blocks. Use a partner or a one-time password.
